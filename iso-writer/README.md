# Web 版 ISO 写入工具

类似 Rufus / balenaEtcher 的网页界面镜像写入工具，纯 Node.js 实现（零依赖），数据仅在本地流转。

## 使用方法

1. **以管理员身份**运行 `start.bat`（或在管理员终端执行 `node server.js`）
2. 浏览器打开 http://localhost:5678
3. 选择镜像（.iso / .img）→ 选择目标磁盘 → 勾选确认 → 开始写入

## 功能

- 本机文件浏览选择镜像，或拖拽/上传镜像直接流式写入（无临时副本）
- 自动枚举物理磁盘，标注可移动/固定磁盘，固定磁盘会额外红色警告
- 写入前尝试卸载目标磁盘上的卷，减少占用冲突
- 1 MiB 块对齐 512 字节扇区写入，实时进度、速度、耗时
- 可选写入后回读校验（浏览方式写入时可用）
- 支持中途取消

## 安全提示

- 写入会**不可恢复地销毁**目标磁盘上的全部数据
- 请务必核对磁盘编号和容量，不要选到系统盘
- 浏览器端必须访问 `http://localhost:5678`，不要暴露到局域网/公网

## 技术说明

- 服务端：Node.js 内置 http 模块，`\\.\PhysicalDriveN` 裸设备写入
- 磁盘枚举：PowerShell `Win32_DiskDrive`
- 需要 Windows + 管理员权限（写入物理磁盘的系统限制）
