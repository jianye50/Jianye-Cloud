博客编辑器

选择仓库里的 blog 文件夹（推荐），
或直接选择某一个文章文件夹单独编辑。授权后即可读写该文件夹内的全部文件。

需要使用 Chrome / Edge 浏览器打开本页。
文章格式：blog/文章文件夹/index.md（Markdown + 头部元信息），封面、背景等图片放在同一文件夹里；
也可以直接把 Markdown 放在 blog/名字.md，图片统一放 blog 根目录。
保存即生效——主页直接扫描 blog 文件夹里的文件夹与文件，不需要任何目录文件。
