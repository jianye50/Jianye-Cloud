欢迎来到博客！这篇文章本身就是一个示例，你可以直接把它删掉。

## 文章放在哪里

每篇文章对应 `blog/` 下的一个子文件夹，文件夹名就是文章链接里的名字：

```
blog/
├── editor.html      ← 编辑器（双击或本地服务器打开）
├── index.json       ← 文章目录（编辑器保存时自动更新）
└── hello-blog/      ← 一篇文章 = 一个文件夹
    ├── index.md     ← 正文（Markdown + 头部元信息）
    └── xxx.jpg      ← 这篇文章用到的图片
```

## 怎么写新文章

1. 用 Chrome / Edge 打开 `blog/editor.html`；
2. 点「选择 blog 总文件夹」并授权；
3. 点「新建文章」，取一个文件夹名；
4. 填标题、日期、标签、摘要，在右侧写正文；
5. 需要插图时点「上传图片」，图片会存进这篇文章的文件夹；
6. 在图片上悬停，可以把它设为**封面**（列表页缩略图）或**背景**（文章页顶部大图），也可以一键插入正文光标处；
7. 点「保存并更新目录」，主页博客列表立刻就能看到。

## 正文支持哪些写法

**加粗**、*斜体*、`行内代码`、[链接](https://example.com)，以及：

> 引用块。工具栏里的「提示块」就是这种带 💡 的引用。

- 无序列表
- 有序列表也能识别
- 分隔线、代码块、图片都支持

写一半想看看效果？点工具栏的「预览」即可。
